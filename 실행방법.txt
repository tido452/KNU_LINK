KNU LINK 실행 안내 (macOS)

1) ZIP을 압축 해제합니다. 파일 이름은 바꾸지 마세요.
2) start.command 를 더블클릭합니다. macOS에서 차단될 경우 우클릭 > 열기를 선택하세요.
3) 처음에는 Python 라이브러리(aiohttp) 설치를 위해 인터넷 연결이 필요합니다.
4) 브라우저에서 http://localhost:8765 로 접속합니다. 자동으로 열리지 않으면 직접 입력하세요.
5) start.command로 열린 터미널 창을 계속 켜두세요. 닫으면 서버가 꺼집니다.

문제 확인
- 브라우저 주소가 file:///.../index.html 이라면 HTML만 연 것입니다. 위의 localhost 주소로 접속해야 매칭이 됩니다.
- 'Address already in use' 가 나오면 8765 포트를 다른 서버가 쓰고 있으니 기존 서버를 먼저 종료하세요.
- 'Python 3이 설치되지 않았습니다' 가 나오면 Python 3.10 이상이 필요합니다.
- 실행 파일이 차단되면 터미널에서 폴더로 이동한 후: bash start.command
- 같은 Mac에서 일반 창과 시크릿 창 두 개를 열고, 같은 모드로 매칭 테스트가 가능합니다.

주의: 현재는 재학생 인증/계정 저장/운영자 심사 없는 개발용 시제품입니다. 공개 인터넷 배포를 하지 마세요.
